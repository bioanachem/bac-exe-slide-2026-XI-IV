第8回 演習問題

【問 1】

固定相としてオクタデシルシリル（ODS）化シリカゲル、移動相としてアセトニトリルと緩衝液（pH 3）の混合溶媒を用いて、ベンゼン、トルエン及び安息香酸の分離を液体クロマトグラフィーにより行った。次の記述のうち、正しいものを２つ選べ。ただし、質量分布比を k とする。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 3, 4

【解説】

  1. 誤り： ODSカラム（逆相）では、疎水性が高い物質ほど固定相に強く保持されて溶出が遅くなります。トルエン（メチル基を有する） ＞ ベンゼン ＞ 安息香酸（カルボキシ基を有し極性が高い）の順で疎水性が高いため、溶出順序は「安息香酸 → ベンゼン → トルエン」となります。
  2. 誤り： 移動相に加える有機溶媒（アセトニトリル）の割合を増やすと移動相の溶出力が強まり、試料の移動相への親和性が増すため、質量分布比 k は小さくなります（溶出が早くなります）。
  3. 正しい： ODSカラムの固定相表面は無極性のオクタデシル基（C18）で覆われており、溶媒和した水分子の排除に伴うエントロピー効果に基づく疎水性相互作用と、化合物との間の分散力（ファンデルワールス力）の両方が関与して保持されます。
  4. 正しい： 安息香酸は弱酸（pKa ≒ 4.2）です。pH 3 の酸性条件では主に分子型として存在するため疎水性が高く強く保持されますが、pH を 7 に上げると解離してイオン型（安息香酸イオン）となるため水への親和性が増し、固定相への保持が弱まって k は小さくなります。
【問 2】

最も強い陽イオン交換能をもつ樹脂の交換基はどれか。１つ選べ。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 3

【解説】

  1. 2級アミン： 弱塩基性陰イオン交換樹脂の交換基として用いられます。
  2. 3級アミン： 弱塩基性陰イオン交換樹脂の交換基として用いられます。
  3. スルホン酸： 強酸性陽イオン交換基（-SO3H）です。ほぼ全 pH 領域で常に完全に解離しているため、最も強い陽イオン交換能を示します。
  4. カルボン酸： 弱酸性陽イオン交換基（-COOH）です。解離度が pH に大きく依存するため、強酸性に比べて広い pH 範囲でのイオン交換能は低くなります。
  5. 4級アンモニウム： 強塩基性陰イオン交換基（-N+(CH3)3 等）です。陰イオンの交換に用いられます。
【問 3】

陽イオン交換クロマトグラフィーによるアミノ酸の分析に関する記述のうち、正しいのはどれか。２つ選べ。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 1, 4

【解説】

  1. 正しい： 陽イオン交換樹脂には、強酸性のスルホ基（-SO3H）や弱酸性のカルボキシ基（-COOH）が交換基として用いられます（強酸性基は常に負電荷を帯びますが、弱酸性基は pH により解離状態が変化します）。
  2. 誤り： 通常、アミノ酸分析は pH 2〜3 程度の酸性緩衝液で開始されます。グルタミン酸（酸性アミノ酸、pI ≒ 3.2）はこの等電点に近く正電荷が最も小さく保持が最も弱く最初に溶出します。グリシン（中性、pI ≒ 6.0）が続き、アルギニン（塩基性アミノ酸、pI ≒ 10.8）は正電荷が最も大きく最も強く保持されるため最後に溶出します（溶出順：グルタミン酸 → グリシン → アルギニン）。
  3. 誤り： 保持された陽イオン性物質を溶出させるには、移動相の塩濃度（Na+などのイオン強度）を高めて対イオンとの競合吸着を強める必要があります。
  4. 正しい： 移動相の pH を上昇させると、アミノ酸の解離状態が変化して正電荷が減少（または負電荷が増加）するため、固定相との静電的相互作用が弱まり、保持された物質が溶出します。
【問 4】

クロマトグラフィーに関する記述のうち、正しいのはどれか。２つ選べ。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 1, 3

【解説】

  1. 正しい： 逆相分配クロマトグラフィーでは疎水性固定相を用いるため、固定相との相互作用が弱く、移動相に分配されやすい（極性の高い）成分ほど先に溶出します。
  2. 誤り： 陽イオン交換クロマトグラフィーでは、塩基性の強いアミノ酸ほど正に強く帯電してマイナスの固定相に強く保持されるため、溶出が最も遅くなります（酸性アミノ酸から順に溶出）。
  3. 正しい： サイズ排除クロマトグラフィーでは、ゲルの細孔に入らず粒子間の隙間を通る排除限界以上の巨大分子から順に、最も早く溶出します。
  4. 誤り： シリカゲルを用いる吸着クロマトグラフィー（順相モード）では、シラノール基の極性・酸性により塩基性の溶質ほど強く吸着・保持されるため、溶出は遅くなります。
【問 5】

日本薬局方ニカルジピン塩酸塩注射液の定量法に関する記述の正誤について、正しいものを全て選べ。

本品のニカルジピン塩酸塩（C26H29N3O6・HCl）約 2 mg に対応する容量（注射液の表示量から換算して量り取る）を正確に量り、内標準溶液 5 mL を正確に加えた後、メタノールを加えて 50 mL とし、試料溶液とする。別に定量用塩酸ニカルジピンを 105℃ で２時間乾燥し、その約 50 mg 精密に量り、メタノールに溶かし、正確に 50 mL とする。この液 2 mL を正確に量り、内標準溶液 5 mL を正確に加えた後、メタノールを加えて 50 mL とし、標準溶液とする。

ニカルジピン塩酸塩の量（mg）＝ WS × ( QT / QS ) × [ A ]

【試験条件】
カラム：内径 4.6 mm、長さ 15 cm のステンレス管に 5 μm の液体クロマトグラフィー用オクタデシルシリル化シリカゲルを充てんする。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 1, 2, 3 （全て正しい）

【解説】

  1. 正しい： 内標準法では目的成分と内標準物質のピーク面積の「比」を用いるため、HPLCへの注入量の微小な変動に対する耐性（自動補正効果）があります。ただし、検出器の直線範囲内を維持するため一定量付近で注入する操作は前提となります。
  2. 正しい： 日本薬局方の試験条件として、充填剤にオクタデシルシリル化シリカゲル（ODS）が指定されているため、これは逆相クロマトグラフィーに該当します。
  3. 正しい： 標準溶液調製において、約 50 mg（WS [mg]）を 50 mL に溶かした液から 2 mL を取って最終 50 mL に希釈しているため、原液からの濃度換算は WS × (2 / 50) = WS / 25 mg となります。試料側と標準側で内標準溶液の添加量（5 mL）および最終全量（50 mL）が共通のため相殺され、定数係数 [ A ] には 1/25（または 2/50）が入ります。
【問 6】

クロマトグラフィーによる物質の定量に関する記述のうち、正しいものはどれか。2つ選べ。

▶ 解答・解説を表示する（クリックで開閉）

【正解】 3, 5

【解説】

  1. 誤り： 「内標準法」と「標準添加法」は異なる定量法です。マトリックス（共存物質）の影響を補正する手法は標準添加法です。
  2. 誤り： 内標準法では、被検成分と内標準物質の変動を同時に補正するため、検量線の縦軸には「被検成分と内標準物質のピーク面積（または高さ）の比」をとります。
  3. 正しい： 内標準物質には、被検成分と挙動が近く保持時間が近接しており、かつ他のどの成分とも重ならずに完全に分離する、化学的・物理的に安定な物質が適しています。
  4. 誤り： 絶対検量線法では注入量の変化や操作のブレがそのまま定量誤差に直結するため、サンプル注入量や測定条件を極めて厳密に一定に保つ必要があります。
  5. 正しい： ピークの近似計算（半値幅法など）では、「ピーク高さの中点における幅（半値幅）」に「ピーク高さ」を乗じることで、良好な精度でピーク面積を算出できます。
