第9回 演習問題

【問 1】

クロマトグラフィーに関する記述のうち、正しいものはどれか。２つ選べ。

  1. カラムの長さが２倍になると、保持時間（tR）は２倍になる。
  2. カラムの長さが２倍になると、質量分布比（k'）は２倍になる。
  3. カラムの長さが２倍になると、理論段数（N）は２倍になる。
  4. カラムの長さが２倍になると、理論段高さ（H）は２倍になる。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 1, 3

【解説】

  1. 正しい： 流速などの条件が同じ場合、移動相の通過時間 t0 はカラム長 L に比例します。保持時間 tR は tR = t0(1 + k') で表され、質量分布比 k' が一定であれば、L が 2 倍になると tR も 2 倍になります。
  2. 誤り： 質量分布比 k' は、k' = (固定相中の溶質量) / (移動相中の溶質量) で表され、分配平衡で決まります。カラムを長くしても、固定相と移動相はカラムのどの位置でも同じ割合で存在し、溶質の分配の割合は変わらないため、k' は一定です。
  3. 正しい： 条件が同じで理論段高さ H が一定である場合、理論段数 N はカラム長 L を H で割った値（N = L / H）となるため、L が 2 倍になると N も 2 倍になります。（※発展事項：Rs ∝ √N より、分離度は √2 倍になります）
  4. 誤り： 理論段高さ H は1理論段あたりの相当長さであり、条件が同じであればカラム長を変えても一定です。なお、カラム長が同じであれば、H は小さいほど理論段数 N は大きくなり、カラム効率は良くなります。
【問 2】

クロマトグラフィーの分離パラメータに関する記述のうち、正しいものはどれか。２つ選べ。

  1. ピーク高さと保持時間が同じなら、ピーク幅が狭いほど理論段数（N）は大きい。
  2. シンメトリー係数（S）が１より小さいとき、ピークはテーリングしている。
  3. カラムの長さが２倍になると、理論段高さ（H）は２倍になる。
  4. 同一の分離条件で２つの化合物の保持時間が同じ場合、両者の分離係数（α）は１である。
  5. 分離度（Rs）は、２つのピークの保持時間の関係を示し、ピーク幅に依存しない。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 1, 4

【解説】

  1. 正しい： 理論段数 N = 16 (tR / W)2 より、保持時間 tR が同じであれば、ピーク幅 W が狭いほど N は大きくなります。
  2. 誤り： ピークの後半が緩やかに下降して尾を引く現象を「テーリング（tailing）」といい、このときシンメトリー係数 S は 1 より大きくなります（1 より小さい場合は、ピークの前側がなだらかに広がる「リーディング（leading）」を示します）。
  3. 誤り： H = L / N であり、N も L に比例するため、条件が同じであればカラム長を2倍にしても理論段高さ H は一定です。
  4. 正しい： 分離係数 α は α = k'2 / k'1 で定義され、2つの化合物の保持時間が同じであれば質量分布比も等しくなるため、α = 1 となります。
  5. 誤り： 分離度は、保持時間の差とピーク幅の両方で決まります（Rs = 2(tR2 - tR1) / (W1 + W2)）。
【問 3】

液体クロマトグラフィーに関する記述のうち、正しいものはどれか。２つ選べ。

  1. 質量分布比（k'）が小さいほど、試料はカラムに保持されやすい。
  2. 理論段数（N）が大きい値を示すほど、優れた分離系である。
  3. カラムの理論段数は、カラムの長さに依存しない。
  4. ピークの完全分離とは、分離度（Rs）1.2 以上を意味する。
  5. カラムの理論段高さは、最適流速で最小となる。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 2, 5

【解説】

  1. 誤り： 質量分布比 k' は、固定相中の溶質量と移動相中の溶質量の比（k' = CsVs / CmVm）です。k' が小さいほど移動相中に存在する割合が大きく、保持されずに早く溶出します。
  2. 正しい： 理論段数 N が大きいほど分離効率が高くなります（ただし分離には選択性 α や k' も関与します）。
  3. 誤り： N = L / H において、理論段高さ H が一定の条件下では、理論段数はカラム長 L に比例して大きくなります。
  4. 誤り： 一般的な目安として、分離度 Rs ≒ 1.5 でベースラインまでほぼ完全に分離されます。Rs = 1.2 はピーク間が谷になる程度の分離であり、定量には不十分とされることが多いです。
  5. 正しい： 最適流速とはバンドの広がりを示す理論段高さ H が最小になる流速です（Van Deemter の式 H = A + B/u + Cu において、低流速での縦拡散 B/u と高流速での物質移動抵抗 Cu のバランスで極小値をとります）。
【問 4】

以下は日本薬局方アセトアミノフェンの純度試験（液体クロマトグラフィー）の記述の一部である。次の記述のうち、正しいものはどれか。２つ選べ。

操作条件
・検出器：Ａ 紫外吸光光度計（測定波長：225 nm）
・カラム：内径約 4 mm、長さ約 15 cm のステンレス管に 5 μm の液体クロマトグラフィー用 Ｂ オクタデシルシリル化シリカゲルを充てんする。
・カラム温度：40℃ 付近の一定温度
・移動相：Ｃ pH 4.7 の 0.05 mol/L リン酸二水素カリウム試液／メタノール混液（4：1）
・流量：アセトアミノフェンの保持時間が約 5 分になるように調整する。
・カラムの選定：本品及び 4-アミノフェノール塩酸塩 0.01 g ずつをメタノール 1 mLに溶かし、移動相を加えて 50 mL とする。この液 1 mL をとり、移動相を加えて 10 mL とする。この液に付き、上記の条件で操作するとき、[ Ｄ ] の順に溶出し、その Ｅ 分離度が 7 以上のものを用いる。

  1. Ａの検出器の光源には、通常、キセノンランプが用いられる。
  2. Ｂのオクタデシルシリル化シリカゲルは順相系の固定相である。
  3. Ｃの移動相中のメタノール含量を増やすと、アセトアミノフェンの保持時間は短くなる。
  4. Ｄは、アセトアミノフェン、4-アミノフェノールの順である。
  5. Ｅの条件をみたすとき、分離度が 1.5 以上であるので、2 つのピークは完全分離している。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 3, 5

【解説】

  1. 誤り： 紫外可視吸光光度検出器の紫外部（225 nm）測定での光源には、重水素放電管（重水素ランプ）が用いられます（キセノンランプは主に蛍光光度計の光源として用いられます）。
  2. 誤り： オクタデシルシリル化シリカゲル（ODS）は無極性固定相であり、極性の高い移動相と組み合わせて用いることで逆相系の分離モードとなります。順相系の固定相ではありません。
  3. 正しい： 流量を一定にした場合、逆相クロマトグラフィーにおいて移動相中の有機溶媒（メタノール）の割合を増やすと溶出力が強まり、保持時間は短くなります。
  4. 誤り： 4-アミノフェノールは、アセトアミノフェンより疎水性が低く、逆相系では保持が弱くなります。さらに、pH 4.7 の移動相中ではアミノ基の大部分がプロトン化され、親水性が増すため、保持がいっそう弱くなります。したがって、先に溶出するのは4-アミノフェノールです（溶出順Ｄ：4-アミノフェノール → アセトアミノフェン）。
  5. 正しい： 分離度が 7 以上であれば条件（Rs ≧ 1.5 のベースライン分離）を十分に満たすため、2 つのピークは完全に分離しています。
【問 5】

液体クロマトグラフィーを用いて生体成分や薬物を定量分析する際には、高感度化や選択性の向上を目的として誘導体化する場合が多い。誘導体化に関する記述のうち、誤っているものはどれか。１つ選べ。

  1. プレカラム誘導体化法では、長時間を要する誘導体化反応を利用できる。
  2. ニンヒドリンを反応試薬として用いるプレカラム誘導体化法によって、アミノ酸を一斉分析することが可能である。
  3. ポストカラム誘導体化法は、試料中の夾雑成分の影響を受けにくい。
  4. ポストカラム誘導体化法では、1つの分析対象物から複数の誘導体が生成しても問題ない。
  5. ジアステレオマー誘導体化法によって、鏡像異性体を光学不活性なカラムで分離することができる。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 2

【解説】

  1. 正しい： プレカラム法はカラムに注入する前に反応を完結させるため、加熱や長時間を要する反応も利用できます。
  2. 誤り： ニンヒドリンは、イオン交換クロマトグラフィー等で分離したあとに反応させるポストカラム法の代表的な試薬であり、プレカラム法の試薬ではありません。
  3. 正しい： ポストカラム法は、夾雑成分をカラムで分離したあとに反応試薬をオンラインで添加するため、試料マトリックス（夾雑成分）の影響を受けにくいという利点があります。
  4. 正しい： ポストカラム法では分離後に反応が起きるため、仮に1つの対象物から複数の誘導体ができてもプレカラム法のようなピーク分裂は起きず、反応生成比が一定であれば定量に支障ありません。
  5. 正しい： 光学活性な試薬を用いてジアステレオマーに変換すれば、光学不活性な（アキラルな）ODSカラムなどで分離が可能になります。
【問 6】

液体クロマトグラフィーを用いた鏡像異性体の分離法には、キラル固定相法、キラル移動相法、ジアステレオマー誘導体化法がある。各法に関する記述のうち、正しいものはどれか。２つ選べ。

  1. キラル移動相法では、分析対象物に対する対掌体を移動相溶液に添加してエナンチオマー分離を行う。
  2. ジアステレオマー誘導体化法は、誘導体化により通常の分配クロマトグラフィーで分離することを目的とする。
  3. あるラセミ混合物を分離したとき、異性体間のピークの分離度（Rs）は 1.2 であった。このとき、2つのピークは完全分離しているといえる。
  4. キラルカラムに固定化される光学活性な高分子として、多糖類誘導体やタンパク質が広く用いられている。
▶ 解答・解説を表示する（クリックで開閉）

【正解】 2, 4

【解説】

  1. 誤り： キラル移動相法は、移動相に光学活性な添加剤を加えることで生じた一過性のジアステレオマー錯体の安定性や分配の差を利用して分離する手法です。
  2. 正しい： ジアステレオマー誘導体化法は、鏡像異性体を物理的性質の異なるジアステレオマーに変換し、通常の分配クロマトグラフィー（逆相カラム等）で分離することを目的とします。
  3. 誤り： 分離度 Rs = 1.2 ではピーク間が谷になる程度の分離であり、ベースラインまで完全に分離された状態（Rs ≧ 1.5 のベースライン分離）とは言えません。
  4. 正しい： キラル固定相法では、セルロース等の多糖類誘導体、シクロデキストリン（環状オリゴ糖）、タンパク質など、不斉認識サイトを持つ光学活性高分子が広く用いられています。
